# パース処理APIドキュメント

## ベースURL: `/parse/`

## エンドポイント

### 1. ディレクトリのパース
- **エンドポイント**: `/parse`
- **メソッド**: `POST`
- **リクエストボディ**:
  - **型**: `ParsingRequest`
  - **説明**: ディレクトリをパースするために必要な詳細情報を含みます。
  - **スキーマ**:
    ```json
    {
      "repo_name": "string",      // リポジトリ名（repo_pathが提供されている場合はオプション）
      "repo_path": "string",      // リポジトリのローカルパス（repo_nameが提供されている場合はオプション）
      "branch_name": "string"     // パースするブランチの名前
    }
    ```
- **レスポンス**:
  - **型**: `ParsingResponse`
  - **説明**: パース処理の結果を返します。
  - **スキーマ**:
    ```json
    {
      "message": "string",        // 確認メッセージ
      "status": "string",         // パース処理のステータス
      "project_id": "string"      // パースされたプロジェクトの一意の識別子
    }
    ```
- **リクエスト例**:
    ```json
    {
      "repo_name": "user/repo",
      "branch_name": "main"
    }
    ```
- **レスポンス例**:
    ```json
    {
      "message": "プロジェクトが正常にパースされました。",
      "status": "READY",
      "project_id": "12345"
    }
    ```
- **可能なステータスコード**:
  - `200 OK`: パースが正常に完了。
  - `400 Bad Request`: 無効な入力データ。
  - `403 Forbidden`: 制限によりアクセスが拒否。
  - `500 Internal Server Error`: 予期せぬサーバーエラー。

## エラー処理

### 一般的なエラーレスポンス
- **400 Bad Request**
  - **説明**: 無効な入力データ。
  - **レスポンス例**:
    ```json
    {
      "detail": "無効な入力データです。"
    }
    ```

- **403 Forbidden**
  - **説明**: 制限によりアクセスが拒否。
  - **レスポンス例**:
    ```json
    {
      "detail": "認証トークンなしではリモートリポジトリをパースできません。"
    }
    ```

- **500 Internal Server Error**
  - **説明**: 予期せぬサーバーエラー。
  - **レスポンス例**:
    ```json
    {
      "detail": "予期せぬサーバーエラーが発生しました。"
    }
    ```

## 追加の注意事項
- ローカルリポジトリをパースするには、環境変数`isDevelopmentMode`が"enabled"に設定されていることを確認してください。
- リモートリポジトリをパースする際は、`user_id`が環境変数`defaultUsername`と一致してはいけません。
